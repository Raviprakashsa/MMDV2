# 17 — Git Strategy

## Executive Summary
Branching, commit, and PR conventions to reduce release friction.

## Branch Strategy
- `main` — production
- `develop` — integration
- `staging` — pre-prod
- `feature/*`, `hotfix/*`, `release/*`

## Commit Convention
- Use Conventional Commits. Example: `feat(reports): add widget pagination`

## PR Workflow
- PR template, reviewers, required checks (lint, typecheck, tests).
